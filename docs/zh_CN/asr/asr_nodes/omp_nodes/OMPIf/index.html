    OMPIf¶

    if: run the region in parallel only when a condition holds.

    声明¶

    语法¶

    OMPIf(expr condition)

    参数¶

    Argument

    描述

    condition

    the condition, of a logical type.

    返回值¶

    无。

    描述¶

    When the condition is false the region runs as if it had not been marked parallel at all, which is how a loop too small to be worth parallelising avoids the cost of starting threads.

    示例¶

    (OMPIf
  :condition (Var
    :v (SymbolRef 1 "run")
  )
)
